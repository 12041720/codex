后续课程维护约定：

1. 每次课程问答按顺序写入 `qa/NNN-主题.md`，保留用户问题、用户答案和助手正式答复。正文可引用同目录中的完整课文，不用摘要代替原问答。
2. 课文写入 `lessons/NNN-主题.md`；提问纠正、补充答疑另外追加问答记录，保留教学过程。
3. 更新路线图的进度，只根据已经展示的练习证据判断掌握程度。
4. 原始附件放在 `sources/`；实际工程代码以后放在 `projects/`，不与 Codex 产品源码混放。
5. 每课明确源码基线、静态核验与执行验证边界。教学示例不冒充真实工具日志。
6. 从第二课开始，课文文件与对话框正式答复必须使用同一份完整正文；问答文件中的助手正文也保持相同。不要另写一个相似版本，不给对话框增加文件中没有的开场或结语。此前课文与问答保持不变。

此约定由后续课程任务执行；当前未安装自动聊天导出服务，也未创建后台自动化。重新开启课程任务时先阅读本文件。
